Secure Secret Architecture

User → CloudCommerce Flask App → Azure App Service → Managed Identity → Azure Key Vault → Payment API Secret

The application does not store payment credentials inside Python files or GitHub. Instead, Azure App Service reads the secret from Azure Key Vault through a Key Vault reference.

Secret value is hidden and never displayed to users

What This Project Proves

  • The payment API secret is not hardcoded in the source code.
  • The secret is stored securely inside Azure Key Vault.
  • The Flask app reads the secret through an environment variable.
  • Managed Identity removes the need to store Azure credentials.
  • RBAC controls which Azure resource can access the secret.

Security Rule

In a real e-commerce SaaS system, payment gateway keys, database passwords, and third-party API tokens must not be stored in code.

This project follows a safer cloud design by separating application logic from sensitive secrets.
